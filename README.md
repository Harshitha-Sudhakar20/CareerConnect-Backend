# CareerConnect Backend

A Spring Boot REST API for a Job Portal application with JWT Authentication and Job Management.

---

## Features

- User Registration
- User Login
- JWT Authentication
- Password Encryption using BCrypt
- Add Job
- Get All Jobs
- Get Job by ID
- Update Job
- Delete Job
- Global Exception Handling
- MySQL Database Integration

---

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- JWT
- MySQL
- Maven

---

## REST APIs

### Authentication

POST /users/register

POST /users/login

### Jobs

POST /jobs

GET /jobs

GET /jobs/{id}

PUT /jobs/{id}

DELETE /jobs/{id}
